Purpose: Expose the raw inputs to the WLS regression for each group.
Each row represents one stage in one year-pair transition.

Columns:
  t0          start year of the year-pair
  stage_label emissions stage (I–V)
  predictor   = (weighted inflow from lower stages) − (proportion at s)
                The regression coefficient λ_CF scales this to predict δp.
                Near-zero predictor → row contributes little signal.

  delta       observed change in proportion: p_{s,t+1} − p_{s,t}
  weight      absolute count at stage s in year t0 (floor 1);

Diagnosis: if CAZ_Plus has many rows with |predictor| < 0.05 and weight = 1,

TEST 3: Pooled variable-speed Phase B — CAZ_Plus + Rest_of_London
────────────────────────────────────────────────────────────────────────
Purpose: Test whether a single λ_CF fits both variable-speed groups.
If the pooled estimate is close to Rest_of_London (0.250) and the
residuals are well-behaved, pooling is the appropriate specification
and the elevated CAZ_Plus estimate is a small-sample artefact.
If the pooled estimate is materially above 0.250, CAZ_Plus introduces
genuine upward pressure that pooling cannot eliminate.

Reference values from step 2:
  B Constant_Speed:  λ = 0.1760  SE = 0.0408  CI [0.0960, 0.2560]
  B CAZ_Plus:        λ = 0.6384  SE = 0.1021  CI [0.4384, 0.8385]
  B Rest_of_London:  λ = 0.2499  SE = 0.0354  CI [0.1806, 0.3192]

New fits:
  B Rest_of_London (refit, confirmation)                   λ = 0.2499  SE = 0.0354  95% CI [ 0.1806,  0.3192]  n = 15
  B CAZ_Plus + Rest_of_London (pooled)                     λ = 0.2480  SE = 0.0552  95% CI [ 0.1397,  0.3562]  n = 15

Interpretation guidance:
  - Pooled estimate close to Rest_of_London → CAZ_Plus rows are diluted
    by the larger ROL dataset; pooling is valid and recommended.
  - Pooled estimate materially above ROL → CAZ_Plus data is pulling the
    estimate up even when outweighed; structural difference, not noise.

TEST 4: Leave-one-out sensitivity — Phase B CAZ_Plus
────────────────────────────────────────────────────────────────────────
Purpose: Quantify how much each individual year-pair drives the elevated
CAZ_Plus estimate. The full fit uses three year-pairs (2021→2022,
2022→2023, 2023→2024), giving 15 GLS rows. Dropping one pair at a time
leaves 10 rows. Large swings in λ when a single pair is removed confirm
instability driven by sparse individual years, not a consistent signal.

Full fit (baseline):
  B CAZ_Plus full (2021→2022, 2022→2023, 2023→2024)  λ = 0.6384  SE = 0.1021  95% CI [ 0.4384,  0.8385]  n = 15

Leave-one-out fits (each row is a pair dropped):
  drop 2021→2022, retain other 2 pairs                   λ = 0.5386  SE = 0.1437  95% CI [ 0.2570,  0.8202]  n = 10
  drop 2022→2023, retain other 2 pairs                   λ = 0.6818  SE = 0.1137  95% CI [ 0.4591,  0.9046]  n = 10
  drop 2023→2024, retain other 2 pairs                   λ = 0.6280  SE = 0.1326  95% CI [ 0.3682,  0.8878]  n = 10

Interpretation guidance:
  - If λ is stable across all LOO fits: the estimate is consistent
    across years; instability is not year-specific.
  - If dropping the 2021→2022 pair produces a large drop in λ:
    this directly supports H2 (boundary contamination); Test 5 follows.
  - If dropping any single pair produces large swings: all pairs are
    high-leverage, confirming H1 (insufficient signal throughout).

TEST 5: Boundary contamination test — Phase B CAZ_Plus, 2022–2024 only
────────────────────────────────────────────────────────────────────────
Purpose: The Sep 2020 policy step-change raised the CAZ_Plus compliance
requirement to Stage IV immediately. Machines arriving in the cold-engaged
fleet in 2020–2021 were subject to this new requirement from day one, so
their stage composition may reflect the shock of the policy change rather
than steady-state natural turnover. The 2021→2022 year-pair captures the
earliest post-step-change transition and is most susceptible to this bias.

This test refits Phase B CAZ_Plus using 2022–2024 only (dropping the
2021→2022 pair). If λ falls toward Constant_Speed / Rest_of_London levels,
the 2021 boundary year is identified as the contaminating factor.

Fits:
  B CAZ_Plus, 2021–2024 (current estimate, reference)    λ = 0.6384  SE = 0.1021  95% CI [ 0.4384,  0.8385]  n = 15
  B CAZ_Plus, 2022–2024 only (boundary pair excluded)    λ = 0.5386  SE = 0.1437  95% CI [ 0.2570,  0.8202]  n = 10

Interpretation guidance:
  - λ drops to ~0.25–0.35 → H2 confirmed; recommend using 2022–2024
    or pooling CAZ_Plus with Rest_of_London as the Phase B estimate.
  - λ remains near 0.64 → the elevated rate is present throughout
    Phase B, not just the boundary year; H1 (signal sparsity) is the
    dominant explanation and pooling with ROL is still recommended.
  - Wide CI in the 2022–2024 fit (only 2 year-pairs, 10 rows) is
    expected and does not invalidate the directional conclusion.
